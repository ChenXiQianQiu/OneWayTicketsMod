```
└── Dictionary<string, IMgr> m_mgrs_dic
    └── ["BackPack"] → World.BackPack.BackPackMgr

```

- 反编译依据：`Decompiled/World/World.BackPack/BackPackMgr.cs:35`、
  `Decompiled/Foundations/Foundations/Mission.cs`（`try_get_mgr<T>`）

## 2. 车辆耐久

```
Foundations.Singleton<WorldContext>.m_instance
├── int caravan_hp
└── int caravan_hp_max
```

- 反编译依据：`Decompiled/World/World/WorldContext.cs:51,53`
- 受击链路：`Caravan.ITarget.hurt`（`Decompiled/World/World.Caravans/Caravan.cs:206`），
  先看 `Config.current.is_player_invincible || WorldContext.world_invincible`，命中才扣 `caravan_hp`。
- `Caravan.Init` 会 `ctx.caravan_hp = _desc.hp`，所以**换车或新开一局时耐久上限会被车辆数据覆盖**，
  这是正常的，不是 Mod 失效。

## 3. 无限耐久为什么用「每 0.2 秒补满」

游戏里有 `WorldContext.world_invincible` 这个字段，看起来像无敌开关，**但不能用**：
它是过场黑屏协程的临时标志（`Decompiled/World/World/WorldSceneRoot.cs:444/455`），
协程结束会自己置回 `false`，外部强行设 `true` 会和过场流程打架。

所以采用「轮询补满」：`WorldService.Tick()` 每 0.2 秒检查一次，
`caravan_hp < caravan_hp_max` 就补到上限。伤害照常结算、UI 照常掉血再回满，
不碰任何游戏状态机。

> 想做真无敌的话，正确入口是 `Config.current.is_player_invincible = true`
> （`Decompiled/Commons/Commons/Config.cs:755`），本 Mod 暂未使用。

## 4. 车辆速度

### 4.1 车速是怎么来的

```
CaravanMgr.tick()                         CaravanMgr.cs:58-81
  ├── in_safe_area → 直接 return（所以安全区里改车速没用，这是对的）
  └── CaravanMover.move()                 CaravanMover.cs:38
        └── 反射调用 CaravanMover_Run.do() （或 Jump / Land / Flying / None）
              ├── caravan_velocity += caravan_acc / 120      CaravanMover_Run.cs:44
              └── caravan_pos.x    += caravan_velocity.x/120 CaravanMover_Run.cs:66
```

- **车速本体**就是 `WorldContext.caravan_velocity`（`WorldContext.cs:25`），x 是前进方向。
- 游戏**没有速度上限**：`tractive_force_max`、`slow_rate`、`boost_rate` 决定的是加速度，
  速度本身由物理自然收敛。所以「保持最大速度」没法靠改某个上限字段实现。
- 游戏自带的最低车速在 `WorldContext.ctx_tick_start`（第 198-202 行）：
  `Config.is_load_caravan_speed_low_limit` 为真时每帧 `velocity.x = max(velocity.x, low_limit)`。
  这只是抬下限，挡不住掉速。

### 4.2 本 Mod 的两个操作

**① 直接设置**（`CaravanSpeedService.SetSpeed`）

```csharp
ctx.caravan_velocity.x = value;   // 下一帧 CaravanMover_Run 就会按它推进
```

面板「局内」页 → 车辆速度 → 输入框 + 「应用」；另有 `+5` / `-5` / `归零` 快捷键。

**② 锁定**（`Patches/CaravanSpeedPatch.cs`）

```csharp
[HarmonyPatch(typeof(CaravanMover), nameof(CaravanMover.move))]
static void Postfix() => CaravanSpeedService.ApplyLock();
```

- 必须放**后置**：前置写的值会被 `move()` 内部的加速度重新算掉。
- `ApplyLock()` 里只做两件事：开关没开就 return；`CaravanMover.move_type != Run` 就 return
  （跳跃 / 滞空期间改水平速度会打乱落地判定）。
- 锁定后每帧把 `x` 钉回目标值，效果就是「不掉速、不减速」。

### 4.3 「本次最高车速」

`CaravanSpeedService.Tick()` 由宿主 `PanelHost.Update` 每帧调用，记录本局观察到的最大
`caravan_velocity.x`。面板上的「取最高」按钮就是把它填进输入框 —— 用来实现
「把车速保持在我跑到过的最高值」这个需求，比手填数字方便。

> 注意：`caravan_velocity` 是**本局**数据，退出探索即失效；
> 锁定开关也只在本次游戏进程内有效，重开一局需要重新确认。

## 5. 作用范围

局内数值只在本局有效：回营地结算时游戏才会把它们换算成营地资源写进存档。
所以这里的修改**不会**直接改存档，和 CE 表的行为一致。
